# Independent full-data audit materials

This folder retains the original ZIP outputs of two separately executed and inspected reconstructions:

- `physical_time/CONFORMANCE_REPORT.zip` — seven CSV/JSON outputs from the main physical-time EMG/Kalman and protocol-prior conformance run.
- `figure4_normalized/FIGURE4_AUDIT.zip` — ten files, including normalized-duration Figure-4 participant contrasts, summary inference, hyperparameters, Subject-6 diagnostics and a Markdown audit.

Both ZIP archives are checked for integrity and their original SHA-256 fingerprints recorded in `../docs/FULL_DATA_VALIDATION_v1.0.3.md`. Extract them to inspect the numerical outputs. The root analysis scripts regenerate the materials using the original CEMHSEY source MAT recordings, which are available from the dataset authors and are not included here.
